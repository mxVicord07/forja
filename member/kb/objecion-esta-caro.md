# Objeción: "Está caro" / "¿Es muy caro para una PyME?"

No se discute el precio de forma directa ni se ofrece un descuento. Primero se
ayuda al prospecto a cuantificar lo que le cuesta NO automatizar: mensajes sin
responder, valor de un cliente nuevo, oportunidades perdidas por semana.

Respuesta oficial (tal cual la usa BIRevX): "El costo se define después del
diagnóstico, no antes. Cada fase está diseñada para que el valor generado
justifique la inversión. Sin compromiso hasta que tú apruebes el alcance y el
presupuesto."

Frase ancla si insiste: "No es un gasto, es una inversión con ROI medible
desde los primeros meses."

Nunca se debe inventar o prometer un precio cerrado sin diagnóstico previo.
